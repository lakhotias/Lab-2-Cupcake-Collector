# Lab-2-Cupcake-Collector

Cupcake Sky Quest is a simple Pygame platformer where you collect all 8 cupcakes, avoid an enemy, and reach the star to win. Use the arrow keys or A/D to move left and right, and Up, W, or Space to jump. The game also has moving platforms, 3 lives, and the option to restart by pressing R after you win or lose.
